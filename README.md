# Harness² RS

### A Rust-Native Implementation of Harness²

Harness² RS is an open-source Rust implementation of Google's
Harness² framework, exploring recursive agent harness optimization,
task-adaptive execution, and cross-task experience learning.

Built with Rust, it provides the foundation for AstraAeon —
an open-source, self-improving AI agent system for macOS.

> Independent community implementation. Not affiliated with Google.
